8ALL — Mehrwege‑Raum der Public‑Ebene
8ALL ist ein neutraler Mehrwege‑Raum innerhalb der iki1uc‑Struktur.
Er zeigt mehrere Wege gleichzeitig, ohne Engine‑Last, ohne Auto‑Moves und ohne System‑Bindung.
8ALL erweitert den klassischen 4ALL‑Raum und macht parallele Abläufe sichtbar.

8ALL ist vollständig neutral, konfliktfrei und MARKT‑3‑kompatibel.

Mehrwege‑Darstellung
